# 2070-S-100-bus-analyzer
An S-100 bus logic analyzer

This project is based on the open source [Logic Analyzer](https://github.com/gusmanb/logicanalyzer) project from Agustín Gimenez Bernad

By using the software from the gusmanb/logicanalyzer repo, a 96 channel logic analyzer can be assembled by installing 4 Raspberry PI PICO boards on this S-100 card and accessed using a USB cable to a PC.
